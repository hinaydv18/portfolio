# Hina Yadav – Data & BI portfolio

Static site (no build step). Open `index.html` or publish with GitHub Pages.

## Publish on GitHub Pages
1. Create a repository and upload everything in this folder (keep the `assets/` and `files/` folders).
2. Repository **Settings → Pages → Deploy from a branch → `main` / root**.
3. Your site appears at `https://<username>.github.io/<repository>/`.

## Edit
- Contact links: top of the `<script>` in `index.html` (`CONTACT`). Empty values are hidden.
- Texts (English and French) and project data: the `P` list in `index.html`.
- Power BI screenshots: add `assets/bi/1.png`, `2.png`… and add one caption per image in the `im:[]` list of the `bi` project.
